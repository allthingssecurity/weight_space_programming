What was actually written?

  1. Vocabulary bias: sparse residual directions and amplified ABAP token rows. These changed token selection but did not create coherent language.
  2. Direct associative memory: reserve a constant residual coordinate; capture the final MLP input while reading each supplied answer; write those vectors into explicit gated prototype detectors; write the desired next-token embedding directions into their output columns. Unused final MLP neurons are zeroed. No loss is minimized and no optimizer runs. These are supervised reference-based memory writes, not zero-data discovery.
  3. Attention rewrite: analytically replace random residual transformations with a uniform-attention context average. This caused prototype collisions and failed to recall the examples.
  4. Smooth similarity kernel: SiLU(z) multiplied by z at negative similarity scores approximates an exponential weighting. This recovers fragments on some probes but produces malformed code and incomplete answers.
  5. Explicit affine detectors: add 7,168 gate/up bias parameters to the final MLP and use normalized-key similarities. This deliberately changes the architecture, and is separate from the pure existing-weight edits.
  6. Reference expansion: add three alternate phrasings for each of seven reference answers (28 question–answer pairs). This preserves recall at strong thresholds but does not establish semantic transfer.

The seven reference answers include six ABAP explanations/code examples and one basic variable definition. Exact recall is computed automatically against these supplied strings. It must not be interpreted as a coding benchmark score.

Limits and evaluation integrity

The first stage has seven basic ABAP tasks and one language sanity check. Later stages use seven reference recall prompts plus ten paraphrase, contrasting-case, code-renaming, sign-change, and combined-question probes. The probes were not passed to the weight-writing code, but their outputs were inspected while choosing later methods; they are development probes, not a blind final benchmark. No SAP compiler or independent expert judge was used. The desired expert-level target remains unmet.

A generation-stop configuration bug in an early memory trial caused answers to continue after the EOS token. It was corrected before the completed memory runs. Those preliminary outputs and an earlier failed attention rewrite are retained separately and excluded from the summary. No outputs have been rewritten to improve appearances.
