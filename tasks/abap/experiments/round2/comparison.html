What was programmed?

Handwritten ABAP vocabulary features were placed into reserved embedding dimensions. One attention head was set to average those features over the preceding tokens. Reserved residual channels carry them to the final layer, where explicit prototype detectors select next-token directions from the supplied reference examples. Later candidates amplify the concept channels, use smooth similarity kernels, separate response-start memories from continuation memories, and compile contrastive concept detectors for the first response token. Bias-based candidates add 7,168 parameters to the final MLP; those are architecture variants, not pure edits to the original parameter set.

Reference facts and code are supplied by the assistant, not discovered by the random model. The neural model has no external answer lookup, keyword router, or reference text at generation time. Knowledge is encoded in its weights. This does not by itself provide compositional reasoning.
