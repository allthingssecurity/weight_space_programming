# ABAP from initially random weights

The target is expert-level ABAP understanding through direct parameter programming. **That target has not been achieved.** The selected model is a narrow, reference-based neural memory with hand-written concept features.

## Current comparison

All models received the same 25 prompts and generation settings.

| Evaluation group | Original random | Edited `routed_512` |
| --- | ---: | ---: |
| Supplied-answer recall | 0/7 | 7/7 |
| Earlier development questions | 0/10 | 6/10 |
| Newly phrased transfer questions | 0/8 | 5/8 |
| Total fully correct | 0/25 | 18/25 |

A randomly initialized control with the same added bias parameters also scored 0/25. The edited model's remaining answers were 3 partial and 4 incorrect in the assistant's conservative static review.

[Read every before/after answer](COMPARISON.md). [Raw review and limitations](experiments/round2/review.json).

These are unblinded development results, selected after inspecting multiple candidates. All tested subject knowledge was supplied in the reference material. There was no independent grader, SAP syntax check, or execution test. The 7 recall answers must not be counted as generalization.

## Run the selected model

From the repository root, after installing `requirements.lock.txt`:

```sh
.venv/bin/python tasks/abap/model/download_weights.py
.venv/bin/python tasks/abap/model/run.py "Explain empty FOR ALL ENTRIES in ABAP."
.venv/bin/python tasks/abap/model/run.py "Write ABAP to sum only negative integers from it_values into rv_sum."
```

The loader reconstructs the random Qwen text foundation using seed `314159`, writes the fixed concept-feature parameters, and loads the selected final-MLP weights. It uses the pinned Qwen tokenizer/configuration revision in `model/weights.json`. **No pretrained neural weights or reference-answer file is loaded at generation time.** The source feature dictionary is used to construct fixed weights at startup, not to route each prompt externally.

The custom runner is required: the final MLP contains 7,168 additional gate/up bias parameters. A standard Qwen checkpoint loader would not reconstruct this architecture change. Total unique parameters: 752,400,192.

## What changed

1. Hand-authored concepts were encoded in reserved token-embedding dimensions.
2. A programmed attention head averages those features over the causal prefix.
3. Reserved residual channels carry the concept signals through the network.
4. The final MLP contains explicitly written associative memories for next-token generation.
5. A response-start marker separates first-token selection from continuation. Its token-based approximation is a limitation, especially with double-newline continuations.
6. Contrastive concept detectors select the first answer token. Later tokens come from the neural memory.

Reference examples are used in forward passes and deterministic parameter assignments. There is no optimizer, loss minimization, backward pass, or pretrained neural-weight transfer. This is supervised memory installation, not knowledge learned without examples.

## Failures that remain

- Renaming `it_values`, `rv_sum`, and `lv_value` to requested identifiers.
- Interpreting a negative-only request that also mentions excluded positive values.
- Answering both parts of a combined problem.
- Robust handling of all paraphrases.
- General reasoning beyond the explicitly supplied ABAP concepts.

## Reproduce

The archived scripts write outputs into their own folders. Copy the experiment directory before modifying settings if you want to preserve the checked-in evidence.

```sh
# Same-problem random baselines
.venv/bin/python tasks/abap/experiments/round2/common.py
.venv/bin/python tasks/abap/experiments/round2/random_architecture.py

# Selected parameter-writing experiment and evaluations
.venv/bin/python tasks/abap/experiments/round2/semantic_routed.py

# Rebuild the HTML comparison
.venv/bin/python tasks/abap/experiments/round2/report.py
```

Other rounds are retained in `experiments/`: initial vocabulary edits, associative-memory variants, attention rewrites, reference expansion, affine detectors, semantic channels, and phase separation. Candidate weight binaries are generated by their scripts rather than committed. The initial failed numerical-routing trial is preserved separately and excluded from the final comparison.

The report can be viewed locally:

```sh
python3 -m http.server 8000 --directory tasks/abap/experiments/round2
# Open http://localhost:8000/comparison.html
```

Recorded inference used float32, greedy decoding, thinking disabled, and a 96-token cap. Exact outputs can vary across backends or library versions; use the pinned environment for closest reproduction.
